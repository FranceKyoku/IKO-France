Automatisation de l'importation des fiches d'identité clubs PDF vers MySQL
Script : import_club_pdf.py Schéma : Create.sql Saison 2026-2027

1. Présentation générale

Ce guide détaille l'utilisation du script import_club_pdf.py pour convertir automatiquement les formulaires officiels « FICHE D'IDENTITÉ CLUB » reçus en PDF par IKO France en fichiers de requêtes SQL transactionnels prêts à être injectés dans la base de données.

Fonctionnalités intégrées :
  • Extraction ciblée : Récupération du club, dojo, professeur, président et contacts administratifs.
  • Géocodage spatial : Résolution automatique des coordonnées GPS via l'API officielle française (WGS84 SRID 4326).
  • Intégrité relationnelle : Respect des contraintes de clés étrangères, UUIDs et unicité de Create.sql.
  • Traitement individuel ou en lot : Traitement d'un PDF isolé ou de tous les PDF d'un répertoire.

2. Prérequis et Installation

Le script s'exécute avec Python 3 (version 3.8+). Une seule bibliothèque de lecture PDF est requise :

pip install pypdf

Note : Si vous utilisez déjà pdfplumber ou PyMuPDF (fitz), elles sont automatiquement reconnues sans installation supplémentaire.

3. Commandes d'exécution

3.1. Convertir un formulaire unique

Pour traiter un formulaire spécifique (ex: Ryuko_Dojo.pdf) :

python import_club_pdf.py Ryuko_Dojo.pdf

Le script génère immédiatement le fichier SQL Insert_RYUKO_DOJO.sql dans le même dossier.

3.2. Convertir tous les formulaires d'un dossier (traitement par lot)

Pour convertir en une seule commande tous les PDF présents dans le répertoire en cours :

python import_club_pdf.py *.pdf

3.3. Définir un répertoire source et un dossier de sortie

Pour scanner un dossier spécifique et sauvegarder les .sql générés dans un autre dossier :

python import_club_pdf.py --dir "C:\Clubs_PDF" --out "C:\Exports_SQL"

5. Injection des scripts SQL en base de données

Chaque script généré est autonome et encapsulé dans une transaction (START TRANSACTION / COMMIT) :

Option A : En ligne de commande MySQL

mysql -u <utilisateur> -p <nom_base> < Insert_RYUKO_DOJO.sql

Option B : Avec un client graphique (MySQL Workbench, DBeaver, HeidiSQL, phpMyAdmin)

  1. Ouvrez votre outil et connectez-vous au serveur MySQL.
  2. Ouvrez le fichier Insert_RYUKO_DOJO.sql dans un onglet SQL.
  3. Cliquez sur Exécuter (Execute Script).

6. Diagnostics & Bonnes pratiques

  • Connexion hors-ligne : Si le réseau est indisponible, le géocodage applique des coordonnées de secours valides sans bloquer la création du script SQL.
  • Unicité des emails : MySQL impose une contrainte d'unicité sur Persons.Email et Contacts.Email. Vérifiez que chaque personne dispose de son adresse propre.
  • Caractères spéciaux & Apostrophes : Le script protège automatiquement toutes les valeurs contre les injections SQL via échappement standard ('').
